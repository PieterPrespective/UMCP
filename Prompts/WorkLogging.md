## Work Logging
- At the start of the assignment make a comprehensive plan for implementation, and log it to the 'Logging Database' marked as 'Planned Approach'
- Store data within the 'Logging Database' in chunks of maximally 512 tokens
- After each development step - update the 'Logging Database':
	- if your findings resulted in a different plan update the ‘‘Planned Approach’ section– but leave the original plan description for reference
	- Add a short description of the work undertaken in this step in mark it ‘Tasklog’, ‘Actions Taken’
